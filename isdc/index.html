THE PATH

Our symbol is how we work

  1. 1INNOVATION

    Idea: every project starts with a dot

    You bring a question or a technical problem. We sit with you to define what has to change, and agree on how success will be measured from day one.

  2. 2RESEARCH

    Research: evidence before opinion

    We review prior work, run the first experiments and document the data every later technical decision will rest on.

  3. 3DEVELOPMENT

    Development: we build what we talk about

    We design the mechanics and electronics, print the prototype, test it, and improve it in iterations until it works as it should.

  4. 4IMPACT

    Impact: the result is the measure

    You receive a tested prototype or a final part, and we measure with you what actually changed against the indicator we agreed on.

      FIVE VALUES

      Five values we work by

      Each value comes with a behaviour we commit to and one we avoid.

      INNOVATION

      The courage to ask

      We look for the unusual solution and test it before judging it.

      • We try fast and learn from mistakes
      • Innovation for show
      RESEARCH

      Evidence before opinion

      Every technical decision rests on data or a documented test.

      • We measure, document and share results
      • Promises without evidence
      DEVELOPMENT

      We build what we talk about

      A prototype says more than any slide deck.

      • We build and improve in iterations
      • Stopping at the idea stage
      COLLABORATION

      Knowledge grows when shared

      We work with universities, industry and young people as partners.

      • We open the lab and share expertise
      • Hoarding or locking knowledge away
      IMPACT

      The result is the measure

      We measure success by what changed, not by activity count.

      • We set the success indicator up front
      • Results that can't be measured
      We don't stop at advice. We build it with you.

      A prototype is more honest than any presentation, so we show you the model instead of describing it.
